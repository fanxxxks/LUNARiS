# LUNARiS · 月面空间重构

本仓库包含离线三维仿真、设计方案、路演材料和建模参考。

| 目录 | 内容 |
| --- | --- |
| [未来工程创新设计](未来工程创新设计/README.md) | 仿真成品、源码、构建工具、材质与设计文档 |
| 文案内容/ | 正式演示文稿、逐页讲稿及不同叙事版本 |
| 素材参考/ | 房间模型、参考图及原始建模素材 |

双击 `未来工程创新设计/月宫华容_三维仿真软件.html` 可离线运行。Windows 使用同目录的 `启动高性能仿真.cmd` 可启用 GLM-5.3 自然语言调度，需要 Node.js 20+ 与本机模型配置。

开发入口、文件依赖和构建命令见[仿真项目说明](未来工程创新设计/README.md)。历史测试脚本、验收记录、重复交付包和一次性生成缓存已从活动项目移除；正式方案与演示材料继续保留。
