# 月序 LUNARIS 5.0 · 月面自主对接母港

双击 `月宫华容_三维仿真软件.html`，用支持 WebGL 的 Chrome 或 Edge 打开。成品已内嵌 Three.js、场景、材质、规划器和界面，可离线演示，也可单独复制到其他电脑。观看成品不需要安装 Node.js。

## 当前场景

24 个独立舱段围绕中央气密核心停靠，各层由环廊连接六个径向泊位。舱段搬运时先离开接口与支承座，径向退出到母港外围，完成转向和跨层飞行，再进入目标泊位；停靠后由泊位承重并机械锁定。外立面朝向径向外侧，舱段背部与中央环廊对接。

| 项目 | V5 配置 |
| --- | --- |
| 空间层级 | L1 至 L5，共 5 层 |
| 对接泊位 | 30 个，每层 P01 至 P06 共 6 个 |
| 初始舱段 | 24 个；L1—L5 分别为 6 / 6 / 6 / 4 / 2 个 |
| 初始空闲泊位 | 6 个，占全部泊位的 20% |
| 舱段外包络 | X × Y × Z = 9.2 × 7.8 × 8.4 m，双层舱内概念布局 |
| 层间距 | 10.8 m |
| 舱段底面标高 | 3.4 / 14.2 / 25.0 / 35.8 / 46.6 m |
| 场景尺度 | 1 场景单位 = 0.1 m |
| 外围转场半径 | 44 m；相对于母港中心，属于规划走廊参数 |

空位比例是泊位占用指标。舱段包络不是可用室内面积；外观中的房间、设备和人物用于说明尺度与功能，没有给出经验证的载员定额。

## 快速运行

1. 打开 HTML，等待月面场景加载。初始为“科研协作”已就绪状态，点击底部“开始演示”。
2. 底部主栏直接选择 **1× / 2× / 4× / 8× / 16×**，默认 **4×**。倍速改变播放时间推进，不改变搬运终态、空间尺度或推力参数。
3. 点击播放按钮暂停或继续；点击“重播”从当前计划开头播放。拖动时间轴会暂停并显示所选模拟时刻。查看对接细节时可改用 1×。
4. 左侧切换任务会恢复统一初始布局、重新规划并自动播放。底部显示当前阶段、完成搬运次数和计划搬运距离。
5. 右侧点击层号进行单层观察；再次点击同一层或点击“完整母港”恢复全部楼层。点击三维舱段或右侧已占用泊位可选中舱段。

“场景与调度”中可启用循环演示与镜头跟随。切换到后台标签页会暂停演示，返回后可手动继续。“模拟急停”冻结演示状态，底部“解除急停”可继续；这是软件暂停与状态检查功能，没有模拟真实飞行器的紧急制动控制。

## 三个预设任务

| 任务 | 搬运与目标 | 建议观察 |
| --- | --- | --- |
| 科研协作 | 3 次转场，将 R02、R03、R08 迁至 L5 | 跨层飞行、科研舱的人员通行距离与最后对接状态 |
| 维修隔离 | 4 次转场，将 R24 移入 L1 · P04，并使相邻的 P03、P05 保持空闲 | 故障舱隔离、缓冲泊位和转运次序 |
| 基地扩建 | 2 次转场，使 L4 入驻数量由 4 增至 6 | 启用预留泊位后的空间组织；全站舱段仍为 24 个 |

每次完整搬运按以下顺序显示状态：

关门隔离 → 断开接口 → 解锁 → 起飞离港 → 外围巡航 → 制动接近 → 软捕获 → 硬捕获 → 检漏 → 均压 → 恢复连接 → 开门 → 停靠完成。

飞行时保持舱门关闭，舱段与母港的连接断开。落座和锁定之后，才进入接口检漏、均压和恢复通行阶段。界面中的速度、推力与接口状态可用于检查这一过程。接口压力状态描述连接区，不能解释为飞行中整个舱内失压。

## 手动搬运：先预览，再确认

推荐用初始布局中的 **R02：L1 · P02 → L5 · P02** 体验一次跨四层搬运。

1. 打开“场景与调度”，取消“封闭 L5 · P03 泊位”，点击“恢复初始舱段布局”。保持演示暂停，并选择“完整母港”。
2. 点击 L1 的 P02 或三维 R02 舱段，核对左侧选中对象。
3. 点击“手动六向调度”。如果当时有舱段正在转场，程序会先让当前舱段完成停靠，再进入手动模式并保留已完成的布局。
4. 在右侧 L5 泊位行中点击第二个空闲位 P02。左侧出现“转场航线预览”，列出起终点与飞行距离；打开“显示转场航线”可在完整场景中查看外围路线。
5. 点击“确认转场”才会执行关门、离座、飞行与对接。点击“取消”只撤销预览，舱段保持原位。
6. 等待本次停靠完成，再选择下一舱段与空位。该示例中舱段底面由 3.4 m 升至 46.6 m。

六向按钮与键盘是目标泊位选择方式：A / D 对应 −X / +X，W / S 对应 −Z / +Z，Q / E 对应降层 / 升层。水平按钮选择该方向的同层泊位，垂直按钮选择相同径向编号的相邻层泊位；实际搬运仍走外围飞行路线。选择较远空位时可直接点击右侧泊位图。

已占用、封闭或不可用的目标会被拒绝，相应方向按钮可能不可用。程序不会为了执行单次手动指令自动搬走目标位置的其他舱段。选择另一个舱段会清除当前预览；切换预设任务会重新开始该任务的初始布局。

## 观察方式与空间分析

| 控件 | 用途 |
| --- | --- |
| 全景 | 查看月面环境、完整母港和总体转场路线 |
| 舱段近景 | 靠近当前选中舱段，观察材质、推进器、散热器和接口细节 |
| 俯视 / 立面 | 比较径向布局、泊位间距与跨层高度 |
| 对接结构 | 暂停并隐藏舱段外形，观察核心、连接廊道与独立支承；恢复播放时返回全景 |
| 自由漫游 | WASD 移动，Q / E 升降，Shift 加速，拖动改变朝向 |
| 人员通行 | 显示任务相关舱段之间经环廊和中央竖向交通的通行图 |
| 舱内剖切 | 在选中舱段近景中显示内部层板、设备与功能尺度，再次点击关闭 |

常规观察时左键拖动旋转，右键或 Shift + 拖动平移，滚轮缩放；触屏双指缩放与平移。空格播放 / 暂停，Esc 关闭面板或退出沉浸显示。自由漫游是观察镜头，没有模拟人员与舱壁的碰撞限制。

“人员通行”的绿色连线来自已停靠舱段、连接通道、环廊和中央竖向交通构成的图；正在飞行的舱段暂不可通行。科研任务比较 R02—R03、R02—R08、R03—R08 三对端点的最短通行距离合计，初始 **164.8 m**，终态 **117.2 m**。这个数值包含环廊步行与中央竖向行程，不是纯步行距离，也不是实际耗时或已验证的工作效率收益。底部“计划搬运距离”则是舱段飞行距离，两者统计对象不同。

## 检查封闭泊位

在“场景与调度”中勾选“封闭 L5 · P03 泊位”，再选择“科研协作”。由于既定科研目标包含此泊位，程序应显示计划不可用并禁止播放；不会无提示地改换目标。取消封闭后会重新生成可用计划，再点击播放即可。

手动模式同样检查封闭目标。已有舱段在转场时，先完成停靠，再修改影响该转场的泊位封闭条件。

## 画质与流畅度

默认使用“精细 · 光影与材质”：保留 **4096 阴影贴图**、精细材质和画面后处理，渲染像素比上限为 1.75。可切换晨光、白昼、夜景并调节曝光；晨光适合整体展示，白昼便于看结构，夜景突出舱内照明。

如设备运行吃力，可主动选择“均衡 · 流畅优先”：像素比上限为 1，阴影贴图为 2048，使用较轻的渲染路径。拖动镜头时不会自动降低已选画质。

程序采用按需重绘：画面静止且没有播放或交互时停止持续绘制；相机操作不重复计算相同模拟状态，转场时主要更新活动舱段，阴影在需要时刷新。这些优化减少重复工作，但不承诺所有设备达到 60 FPS。

设置面板显示 FPS、P95 帧耗时、绘制次数和三角形数量。FPS 与 P95 是活动渲染样本的参考读数，静止时保留最近结果；它们不能代替目标设备上的完整 GPU 性能测试。实际流畅度还受显卡、分辨率、浏览器和窗口大小影响。

## 导出与概念参数

点击“导出三维仿真记录”下载 `LUNARIS-XYZ-simulation.json`。文件名保留兼容命名，内部 `version` 为 **5.0**，包含配置、初始布局、泊位、任务、搬运路径、阶段时序、预计模拟时长、操作事件、封闭泊位与当前状态。

当前状态包含舱段位置、朝向、速度、推力、质量、理想推进剂消耗和接口状态。原始坐标使用场景单位，换算米时乘以 `metresPerSceneUnit = 0.1`；朝向按文件定义的 Euler YXZ 顺序读取。部分旧兼容字段仍可能保留，`shafts` 为空，不表示场景中存在搬运升降机构。当前界面提供导出，没有记录导入按钮。

动力估算采用可修改的概念假设：每次转场起始总质量 45,000 kg（含当次推进剂）、月球重力 1.62 m/s²、额定总推力 140 kN、比冲 320 s。程序根据规定航迹的加速度与抗重力需求估算推力，积分理想推进剂消耗并使质量递减；每次转场重新采用参考起始质量。

这一模型没有完成具体发动机与油箱选型、姿态控制耗量、推进剂储备、喷流月尘、结构承载、气密材料或环境试验验证。近月面飞行边界与对接阶段也是参数化概念表达。软件用于检查几何、占位、航迹与操作时序，不是已认证的真实飞行控制系统。原 800 × 600 mm 二维磁牵引样机与 V5 推进器搬运架构分属不同验证阶段，前者不能证明后者的动力可行性。

## 源文件、构建与检查

| 文件 | 用途 |
| --- | --- |
| `月宫华容_三维仿真软件.html` | 可独立离线运行的最终成品 |
| `simulation-core.js` | V5 泊位、飞行规划、时序、动力估算与人员通行图 |
| `lunar-scene.js` | 月面环境、母港、舱段、材质与渲染 |
| `lunar-app.js` | 播放、手动预览确认、交互、分析显示与记录导出 |
| `lunar-ui.html` | 当前界面与样式模板 |
| `build-simulation.cjs` | 检查脚本语法并将当前源码打包为离线 HTML |
| `可重构月球科研站_自主对接母港方案_V5.docx` | 当前方案与分阶段验证计划 |
| `自主对接母港设计说明.md` | 当前架构、尺度、接口与模型边界 |

修改源码后，需要重新构建 HTML 才能在成品中看到改动。历史版文件保留用于对照；`simulation-app.js` 与 `simulation-ui.html` 不属于当前构建入口。

在项目目录打开终端，使用可用的 Node.js 执行构建与三类自动检查：

```powershell
node build-simulation.cjs
node simulation-test.cjs
node lunar-validation.cjs
node .codex-review/v5-performance-test.cjs
```

`simulation-test.cjs` 检查 V5 规划、碰撞包络、阶段连续性、接口顺序、参数约束与终态；`lunar-validation.cjs` 检查打包成品和界面联动；性能脚本检查静止时停止重绘、交互响应、局部更新与倍速推进等行为。集成和性能检查中 GPU 使用替身，不能证明真实设备的画面效果或帧率。

构建后还应在浏览器中依次查看三个任务终态、R02 手动预览与确认、人员通行图、舱内剖切、封闭 L5 · P03 后科研计划被拒绝，以及精细画质下的拖动和缩放。记录目标设备上的表现，再判断是否需要选择均衡画质。
