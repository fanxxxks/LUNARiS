# 月序 LUNARIS 三维仿真软件 2.0

双击 `月宫华容_三维仿真软件.html`，在支持 WebGL 的 Chrome 或 Edge 中打开。三维库已内嵌，不需要联网、安装或启动服务器。保留 HTML 原文件即可使用。

1. 打开后直接点击底部“开始演示”。基础任务已经自动准备好。
2. 点击左侧“舱段换位”“科研协作”或“维护调度”，会自动规划并开始演示，无需另点规划。
3. 点击“建筑近景”查看舷窗、气闸与屋顶设备；“全景”回到聚落。“俯视”看布局，“机构剖视”暂停动作并展示面板下的共享机构。
4. 拖动旋转，滚轮缩放；触屏支持双指缩放。底部可以暂停、重播和拖动进度。
5. 顶部“沉浸展示”收起说明，适合大屏；点击“退出沉浸展示”或按 Esc 恢复。空格播放或暂停。

高级功能都在“更多”：播放速度、建筑名称开关、循环、通道封闭、自定义目标、记录导出和模拟急停。自定义R1–R8必须各出现一次，然后点击“应用布局并演示”。修改目标但尚未应用时，仍保留已有计划；导出记录对应已应用的目标。

月面地形、陨石坑、弧形建筑、舷窗、气闸、能源阵列、通信天线和巡视车均为三维概念场景。运输路径与实物的平面机制一致；建筑外观与高度用于展示，不是加工尺寸图。

## 仿真假设

- 800×600 mm 平台、60×40 mm 舱段；八个泊位和一个等待位。
- 单机构串行搬运。置换循环借助等待位分解；各段路径进行正交图搜索。
- 采用矩形扫掠安全间距：舱段中心间至少满足 X 方向66 mm或Y方向46 mm。中央障碍按舱段半尺寸加余量膨胀。
- 拖动段端点停稳，80 mm/s为假设峰值。吸合、释放各假设1秒。默认2倍播放只改变观看速度，时间轴显示模拟时间；空载定位和空返假设匀速，不构成电机控制代码。
- 只计算几何和时序；不计算磁力、摩擦、变形、月尘、热真空、自动接口或人员安全。不提供垂直搬运。
- 每次规划从统一初始布局开始，不支持中途任务接续或随机机械故障模拟。不是数字孪生或实机控制器。

## 验证与路演前检查

规划核心含自动测试：`simulation-test.cjs`，可用 Node.js 运行。覆盖基本交换、多循环、长循环、200组可复现排列、终态与扫掠碰撞检查、重复目标和封闭区域拒绝。

`lunar-validation.cjs`另行检查三维场景构建、脚本语法、一键任务、暂停、视角状态、急停恢复、任务终态、封闭区、沉浸退出与错误目标。该测试使用模拟DOM和渲染器，不是浏览器视觉验收。

浏览器工具此前因安全策略拒绝本地HTML访问；本轮未绕过限制，尚未完成真实浏览器截图和视觉验收。在路演电脑检查画面、视角、播放、沉浸退出与记录下载是否正常。

源码说明：`simulation-core.js`为规划与状态计算；`lunar-ui.html`为新版界面；`lunar-scene.js`为新建月面与建筑模型；`lunar-app.js`为新版交互。`build-simulation.cjs`只复用原HTML内嵌的Three.js库，生成离线文件。`simulation-ui.html`和`simulation-app.js`是保留的第一版源码，不再参与构建。
