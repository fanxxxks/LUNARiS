# 月序 LUNARIS 3.0 · 三层 XYZ 建筑调度

双击 `月宫华容_三维仿真软件.html`，用支持 WebGL 的 Chrome 或 Edge 打开。Three.js、材质纹理、建筑模型、规划器与界面全部内嵌，无需联网或安装依赖。HTML 可单独复制到其他电脑演示。

## 本次升级

- 从 8 个小舱段扩展为 **36 座大型建筑、3 层空间、39 个泊位**，其中 3 个为升降缓冲位。
- 每层 4 × 3 座建筑紧密排列。单栋运输包络为 23 × 19.5 × 21 m；水平建筑间距 1.5 m，相邻泊位单元的建筑覆盖率约 87.6%。这是建筑概念尺度。
- 三层泊位高度分别为 Y = 6、30、54 m。建筑沿 X/Z 平移，通过右侧升降塔沿 Y 轴跨层运输。
- 六类立面、金属蒙皮、舷窗与局部室内照明、屋顶能源设备、导轨、支柱、伸缩升降托架、太阳能阵列、通信天线、巡视车与维护人员。
- 程序生成的月面地形、陨石坑、岩石和细颗粒材质；物理材质、反射环境、方向光阴影、色调映射与轻量辉光。
- 建筑采用实例化，固定构件按材质合并；整场约 34.4 万三角形、123 个网格对象。实际帧率取决于电脑与浏览器，可切换均衡画质。

## 观看演示

1. 点击“开始演示”，或直接点击任务。
2. **跨层换位**：交换 L1、L2 的两个建筑，利用 L3 升降缓冲位让行。
3. **三层重组**：在三个高度层之间进行循环重构。
4. **街区平移**：紧密建筑沿 X/Z 有序让出空位，并恢复空闲升降位。
5. 底部可暂停、重播、拖动时间轴。时间轴显示模拟时间；播放倍率只改变观看速度。
6. 右侧楼层图中，点击层号可单独观察该层；点击“完整建筑群”恢复全景。小格可选择建筑。

跨层动作包含：空载托架收拢至塔外、升降机构定位、托架展开、泊位解锁、水平转运、Y 轴升降、停靠锁定。空载归位时托架收拢，避免穿过已经停在升降位的建筑。

## 手动六向调度

点击“手动六向调度”，再点击场景里的建筑或右侧对应格位。使用面板上的 ±X、±Y、±Z 按钮：

| 操作 | 键盘 |
| --- | --- |
| X 方向平移 | A / D |
| Z 方向平移 | W / S |
| 沿升降塔下降 / 上升一层 | Q / E |

手动模式保留已经完成的布局；如果建筑正在运输，会先让当前建筑停靠，再进入手动模式。每次搬运完成后才能下达下一次指令。

建筑只能移向可达空位。灰色按钮代表相邻位置占用、轨道边界或封闭。普通建筑泊位之间不允许直接垂直穿过楼板，必须先将建筑平移到右侧升降塔。

一个容易上手的操作：恢复初始布局 → 开启手动调度 → 选择 L1 的 08 号建筑 → **+X** 进入升降塔 → **+Y** 升到 L2 → 再次 **+Y** 升到 L3。也可点击空闲升降格位，让规划器寻找可达路径。

“恢复初始建筑布局”在设置内。点击其他演示任务也会从统一初始布局重新开始。

## 镜头与画面

- 左键拖动环视，右键或 Shift 拖动平移，滚轮缩放；触屏双指缩放和平移。
- 建筑近景、俯视、立面和结构分解，可从顶部切换。
- **自由漫游**：WASD 在场景中移动，Q/E 改变观察高度，Shift 加速，拖动改变朝向。漫游是观察工具，不计算镜头与建筑的碰撞。
- **结构分解**会暂停搬运并展开楼层，展示轨道与骨架；展示偏移不会改变实际调度坐标。
- 设置提供晨光、白昼、夜景、曝光、精细/均衡画质、轨迹、标注、镜头跟随和循环演示。
- “沉浸展示”收起侧边说明；点击退出按钮或按 Esc 恢复。
- 模拟急停保持当前建筑位置；解除后继续，不会重置布局。

## 几何与仿真假设

坐标采用 X 水平、Y 竖直、Z 纵深。一个场景单位对应 0.25 m；记录中保留原场景单位，并写明换算比例。建筑运输包络为 92 × 78 × 84 场景单位，泊位间距为 X 98、Y 96、Z 90。

规划在三维邻接图上搜索空闲路径。仅升降塔存在跨层邻接；建筑路径使用连续轴向扫掠 AABB 检查，并保留 0.5 m 的建筑间安全余量。满载移动使用平滑加减速，转向前在路径端点停稳；单机构串行调度，不进行并发搬运。

原 800 × 600 mm 的平面样机与此次大型建筑概念不是同一尺寸模型。这是几何与动作时序演示，尚未计算承重、动力、稳定性、磁力、环境与实际控制；界面中的高度和速度不能直接用于施工或电机参数。

## 导出与源码

设置中的“导出三维仿真记录”生成 JSON，含当前计划的起始布局、泊位坐标、路径、动作时序、当前 XYZ 状态、封闭节点与事件。手动模式会记录每次已发出的动作；`moves` / `phases` 表示当前一次搬运，先前手动指令在 `events` 中。

- `simulation-core.js`：三维路径、扫掠检查、预设任务、升降机构时序与可回放状态。
- `lunar-scene.js`：离线材质、建筑、月面环境、实例化与渲染。
- `lunar-app.js`：镜头、任务、手动调度、分层、播放和记录。
- `lunar-ui.html`：响应式界面。
- `vendor/three.min.js`：本地 Three.js r160；构建不再依赖已缺失的旧 HTML。
- `build-simulation.cjs`：在任意工作目录运行均可生成最终独立 HTML，构建时先检查脚本语法。
- 原版文件已保存在 `.codex-review/pre-density-3d/`。`simulation-ui.html`、`simulation-app.js` 是第一版历史源码，不参与当前构建。

运行构建与检查：

```powershell
node build-simulation.cjs
node simulation-test.cjs
node lunar-validation.cjs
```

自动检查覆盖 36 座建筑实际几何包络、三种任务、连续扫掠、1,000 次可复现随机移动、升降中间态、终点、反向拖动时间轴、占位守恒、封闭升降塔、暂停/急停、手动 X/Y 操作、分层、画质、漫游和导出。`lunar-validation.cjs` 使用真实 Three.js 几何与模拟 GPU，因此另行进行浏览器画面和交互检查。

2026-09-07 已在真实浏览器检查 1440 × 900、1280 × 720 和 390 × 844 布局，验证 X 向入塔、Y 向上升与返回、升降途中暂停、原生时间轴终点、单层观察、夜景切换和面板间距。控制台未发现运行错误。原生滑块的浮点取整问题已修复，拖到末端会正确完成停靠并解锁后续手动操作。
