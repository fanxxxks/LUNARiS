# 可重构月球科研站 巨构框架方案 V4

方案采用不规则巨型框架、中央贯通空腔及嵌入式功能房间。骨架以错层、退台、局部悬挑和高低不同的结构跨形成整体轮廓；房间按用途形成局部组团，留出可见轨道、等待泊位与维护空间。

## 固定参数

| 项目 | 概念设定 |
| --- | --- |
| 层数与节点 | 5层，42个有效轨道节点／泊位 |
| 房间与余量 | 24个房间，18个初始空闲节点，占42.9% |
| 水平泊位间距 | X方向31 m，Z方向30 m |
| 最大运输包络 | X 23 m × Y 19.5 m × Z 21 m，包含最大外形控制范围 |
| 相邻水平净距 | 以最大包络计算，X方向约8 m，Z方向约9 m |
| 垂直层距 | 27 m |
| 泊位基准高度 | Y = 8.5／35.5／62.5／89.5／116.5 m |
| 内部竖向轨道 | A(-1,0)和C(0,-1)贯通5层；B(1,0)贯通L1至L4；括号为(col,row) |
| 中央空腔 | col 0、row 0贯通，不作为可进入的运输节点 |
| 同时运输 | 一个房间，其他房间保持停靠 |

这些数值用于宏观概念与几何仿真。最大包络不是可使用的室内尺寸；高度基准不是室内净高；18个初始空闲节点并不全部等同于永久交通空间。结构尺寸、载荷与人员使用条件需进一步设计。

各层节点数／初始房间数依次为L1 14／9、L2 11／6、L3 8／5、L4 6／3、L5 3／1。列坐标col取−2至2，X = col × 31 m；行坐标row取−1至1，Z = row × 30 m。各层只保留有效节点，并非每一层都铺满完整网格。

## 空间与运动逻辑

房间在主框架内沿X、Z轨道平移，先到达有连接的内部升降节点，再由托架沿Y轴跨层。路径遵守节点邻接、实际包络和占位约束；不存在任意飞行或穿越中央空腔的捷径。框架支撑应布置在运动包络之外或明确纳入不可通过区域。

工程深化的动作顺序为：核对路线与服务接口 → 托架接管载荷 → 解锁 → 导向平移或升降 → 泊位定位与锁定 → 托架卸载。电力、数据、流体、热控及载人通道的隔离和重接需要各自的接口规程。软件表现的托架、锁扣和导向并不构成真实传感互锁或承载试验。

三条竖向轨道增加路线选择，但是否能够在一条失效后继续运输取决于有效连通与占位。空位比例较高也不能保证任何目标均可达；规划无解时应给出明确原因。

## 三类任务

| 任务 | 调度目的 | 需要看见的结果 |
| --- | --- | --- |
| 科研协作 | 将R02、R03、R08调至L2，同层协作房间0→3 | 参与模块、前后位置、路径、跨层次数及终态 |
| 维修隔离 | R24从顶层移至首层东侧检修位，附近两个普通位留空；R11补入顶层 | 让位、隔离缓冲、运输和停靠；位置移开不等于气密或污染隔离完成 |
| 基地扩建 | 激活L2两处预留位，L2入驻6→8，全站总量仍为24个房间 | 既有房间的重组结果；并非自动制造或安装新房间的证据 |

任务指标包括房间搬运次数、载房间路径距离、升降段数与累计Y行程、占位检查、实际终态和运行事件。播放倍率与展示时长不直接代表真实效率、能耗或成本。比较方案须保留初态、目标和约束。

## 视觉设计要求

- 总览以结构跨、高度、中央空腔与人员车辆参照表达规模，房间之间保留可读间隔。
- 框架、轨道和舱体分别采用哑光金属、受控金属反射与微粗糙外壳；玻璃表现局部反射和内部层次。
- 近景交代连接节点、桁架、轨道、导向轮、锁扣、运输底盘、维护走道、板缝与设备接口。
- 用有方向性的主光、投影、接触阴影与月面起伏建立落地关系；暖色室内灯光和冷色导向灯只在局部强调。
- 控制辉光与曝光，保持结构轮廓和路径可见。艺术化补光是展示参数；月面环境不以地球式云雾解释。
- 保持总览、分层、房间近景、机构和任务观察各自清楚，避免高亮和标签遮挡关键动作。

## 实物路线与验证边界

原800 × 600 × 100 mm底座、4 mm面板和八个轻质模型的XY磁牵引原理样机继续保留。重量由面板支撑，磁头的升降用于吸合／释放，不能当作房间垂直运输。V4宏观三维框架与它具有不同的载荷、锁定和驱动问题。

建议按“平面原理复测 → 单层承载底盘与锁定 → 两层升降及制动 → 多层调度与故障恢复 → 标准接口及环境专项验证”推进。原方案20次连续测试、19/20成功及≤5 mm定位误差均为建议目标，实际结果应由原始记录填写。

当前仿真只支持几何、占位和动作时序的证据。机械强度、挠度、竖直驱动、制动保持、断电状态、接口、载人安全、热真空、防尘和寿命需要独立验证；不填写未经测量的性能、认证或月面适用性结论。

## 原方案观点的改进

保留共享搬运、被动模块、等待位周转、可复查试验记录和谨慎创新表述。空间表达改为不规则巨构，运动解释扩展到框架内XYZ迁移，任务演示围绕协作、维修和扩建的价值展开，实物路线增加真正的双层升降与泊位载荷交接。
