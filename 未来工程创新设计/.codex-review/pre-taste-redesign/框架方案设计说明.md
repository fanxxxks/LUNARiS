# 可重构月球科研站 · 紧凑模块聚落方案 V7

第七版延续 V6 的精简框架和内部机械搬运，新增六面舱口、相邻气密短接的几何表达、人流热图与分档渲染工作台。房间如积木般紧密堆叠，以错层、退台、局部悬挑和中央留空形成不规则聚落；框架收进楼板与接缝，房间的体块、尺度和生活科研细节成为画面主体。月面背景继续保留。

## 教室尺度与面积口径

扩大后的单间外部平面为 11.5 × 10.5 m。室内基准矩形 10.25 × 9.125 m 面积为 93.53125 m²，扣除 1.75 × 1.75 m 竖向孔洞得到约 90.47 m²；继续扣除圆角地板边界后约为 90.1 m²。界面采用“单层约 90 m²”的简洁口径，家具、实验台、设备柜和其他固定设施占用另计。

这里的单层指一个室内层面，不把上下两层相加后称为单层面积。面积扩大应落实到实际壳体、地板、舱口、前室和搬运包络；尺度换算仍为 1 场景单位对应 0.1 m，不能只改变标注文案。

“教室尺度”用于说明单个房间的面积和空间感，是设计参照，并非教室规范认证、核定班级人数或建筑使用许可。后续应按具体科研、居住和设备用途分别核对净尺寸、采光、声学、消防、检修与疏散条件。

## 功能色与识别层级

六类房间采用固定功能色：材料 MAT 蓝色 `#3e9dcc`、生命 BIO 绿色 `#62ae85`、居住 HAB 沙色 `#d5af75`、能源 PWR 橙色 `#d28a48`、物资 LOG 陶红色 `#be716f`、通信 COM 紫色 `#978cc7`。颜色与功能牌号共同识别类型，R01—R24 编号区分独立房间。

三维模块、地图占用格与房间检查器采用相同映射；选中态使用亮边和中心点，保留功能色。空位、升降节点和人流热图继续使用各自的状态表达。功能色宜用于可读的壳体分区、设备和标识，不取代材料的金属、玻璃与室内层次。

## 总体形态与结构表达

底部房间组团较完整，上部逐层收退，避免规则塔楼式重复。框架以少量关键立柱、楼板边梁、舱底支承和接缝连接件表达承重关系；近景保留必要的导向、锁扣、服务接口和维护细节，远景以紧密体块读取整体。

局部悬挑需要明确回传至主结构的载荷路径。楼板和边梁应避开正在使用的搬运包络，不能仅通过隐藏构件掩盖结构冲突。房间落位时由固定支承承担载荷，搬运机构只在规定阶段接管。

可见的双层室内布置用于说明生活、科研与设备空间的尺度。人员参照、窗洞、设备柜和门高应彼此一致；外部散热板、通信与电力接口需要注明功能，具体面积与容量随热负荷和任务深化确定。

## 内部搬运逻辑

房间沿连通节点在 X、Z 方向平移，跨层必须经 A / B / C 内部升降通道。规划检查当前占位、相邻连接与连续扫掠包络，不允许穿越中央留空或跳过阻挡房间。较远目标通过多个相邻节点到达。

当前动画明确区分房间移动与空载机构调整：机构收拢 → 空载换层 → 展开接管 → 房间解锁 → 平移或带载升降 → 落位锁定。是否需要空载调整取决于机构的当前高度。一次只搬运一个房间，三套机构的状态独立记录。

实际工程顺序还需包括载荷接管确认、接口隔离、位置与锁定反馈、制动冗余及断电保持。收拢与展开的概念动画不等于真实机构的强度和稳定性验证。紧凑布置尤其需要检查机构突出部、局部悬挑、附件和检修空间。

三条通道提供替代路线，但能否改道同时取决于占位与连通。当前科研初态下，封闭 L2 · C 可以通过 A / B 完成同一终态；这不意味着任意故障和任意布局都能自动恢复。

维修缓冲只表示空间留空。若目标是气密、污染、火灾或设备故障隔离，还需要对应接口、舱门、环境和运维设计。

## 六面接口与人员连接图

每个房间在 ±X、±Y、±Z 六面设置可收回舱门、接口框和通行开口。水平接口通向舱内公共前室；上下接口通过偏置竖向前室和梯段连接。原有室内层板在竖向通道处留出开口，使舱门、通道与室内路线在几何上相互对应。

| 接口 | 局部中心位置，单位 m | 相邻接口之间的概念距离 |
| --- | --- | --- |
| +X / −X | (±5.75, 2.6, 0) | 1.0 m |
| +Z / −Z | (0, 2.6, ±5.25) | 1.2 m |
| +Y | (3.0, 7.65, −2.875) | 与上层 −Y 接口相距 1.58 m |
| −Y | (3.0, 0.03, −2.875) | 与下层 +Y 接口相距 1.58 m |

局部坐标以房间底面锚点为原点，加上房间锚点即可得到世界位置。竖向接口距离与 1.4 m 外包络净距不同，因为接口中心位于各自顶底面以内。

人员网络只连接**正交相邻、已落位且可通行的房间**。两个相向舱口之间建立短套筒，包含壁体、框架、侧窗及空心通道；垂直短接与舱内梯段对齐。空泊位、中央留空与空货运井不形成桥接，也不允许跨越中间房间。货运节点图、A / B / C 升降托架与人员图分别建模。

初始布局存在 **3 个连通分量**：主组团含 21 个房间；R03 是独立分量；R17 与 R22 组成一个两房间分量。因此初始聚落不是全站互通。新版本明确暴露这一空间缺口，不能以可见短接替代全站连接检查。

当前搬运时序表达“舱门关闭 → 服务隔离 → 短接收回 → 房间搬运 → 短接恢复 → 服务恢复 → 舱门开启”。房间解锁后从可用人员网络移除，直到落位并完成连接才恢复通行；房间门扇向壁内收回，短接向各自舱口收拢。主界面可查看选中房间的已连接方向，显示开关只控制短接的观察，不改变人员图的计算条件。

上述气密短接是具有实际对应门位和相邻关系的概念几何。软件不求解气压、泄漏、均压、密封寿命、互锁可靠性和火灾分区。工程接口还应分别定义机械、供电、数据、流体、热控及人员功能，并验证载荷接管、隔离反馈、锁定保持、检漏与开门许可。

## 模拟人流热图与评价口径

热图以当前人员图为基础，把假设的起终点需求按用途权重分配到最短路径。界面输入范围为 0—300 人次/分钟，默认 120 人次/分钟；三种场景分别为日常通勤、科研协作和应急集合。

| 场景 | 需求方向与假设 |
| --- | --- |
| 日常通勤 | 居住舱到工作舱，实验目标权重 3，能源与通信 1.5，物流 1 |
| 科研协作 | 实验舱互访权重 3，实验至物流 2，物流至实验 1 |
| 应急集合 | 非居住舱到居住舱的等权集合需求；不代表经过验证的避难目的地或疏散方案 |

舱内连续色场与连接热度从蓝、青、绿、黄到橙表达分配强弱，方向粒子辅助识别流向。颜色和粒子均由假设需求生成，不是实测人员定位、人体密度或传感器结果；单个粒子没有“一个真实人员”的对应关系。

成功分配的需求计入通行人次，单条短接的最大分配量计为峰值；无法到达目标的需求单独统计，**不重新分配给其他舱段**。全站输入需求等于可达分配与不可达需求之和。跨越多条短接的同一需求会出现在各边流量中，不能将所有边流量相加当成独立人数。

模型不含通道容量、排队、拥堵反馈、碰撞避让或个体行为，也不计算疏散完成时间。房间移出或恢复时更新连通关系，便于在相同输入条件下比较空间重组前后的可达性与流量集中位置。三任务的既有搬运终态、同层房间数和留空位仍是独立的布局指标，不能预设搬运必然降低所有人流指标。

## 画面、交互与性能

本轮界面改用石墨灰、骨白与信号橙，分别建立背景、信息和操作强调的层级；六类房间的功能色保持原有映射。工作台继续组织任务、房间检查、三维画面、楼层地图和播放状态，地图保留五层不规则 5×3 格位，热图卡展示需求与可达结果。字级、分隔线和留白共同服务于阅读与观察。

中文采用 Lunaris Sans（Noto Sans SC 子集），标题与数字采用 Lunaris Display（Space Grotesk 子集）。字体及 OFL 许可信息嵌入单文件 HTML，离线演示不依赖外部字体请求。`vendor/fonts/` 保存字体、上游源文件、许可与构建记录；`build-fonts.py` 和目录内维护说明提供可重建流程。

形态继续由紧凑体块、退台阴影、薄楼板和板缝表达尺度；模块保留已建模的设备、舱内层板、六向舱口、前室和人员参照。此次光照中和偏黄色调，强调陶瓷白舱体与冷银金属框架；离线反射环境、PBR 材质、玻璃反射、阴影、环境遮蔽和克制辉光共同保留材料层次。本轮视觉与字体改造没有新增渲染通道、几何或游戏功能。

全景、单层、近景、框架透视、舱内剖切与自由漫游分别服务于总体形态、房间尺度、机构和内部空间的观察。近景暂停并隔离所在层；全景恢复全部层级。手动调度保留路线预览、确认、取消、急停和导出；播放支持 1 / 2 / 4 / 8 / 16 倍，默认 4 倍。

| 渲染档位 | 当前实现 |
| --- | --- |
| 精细（默认） | 精细几何与材质、4096 阴影、半分辨率环境遮蔽、辉光和抗锯齿 |
| 极致 | 提高像素密度与环境遮蔽采样，保留 4096 阴影；静止后积累 8 帧亚像素偏移样本 |
| 高帧 | 保留模型与材质细节，降低像素密度、使用 2048 阴影并关闭环境遮蔽采样 |

离屏 MSAA 在设备支持范围内选择采样数，自动模式同时使用 FXAA；显式 MSAA 不可用时回退 FXAA，也可单独选择 FXAA。极致静态积累在运动时重置，停止运动后完成 8 帧精修并释放持续刷新。高帧档是减少渲染开销的选择，不是固定帧率承诺。

目标帧率提供 30 / 60 / 120 FPS，默认 60；它控制绘制调度目标。内置镜头基准暂停搬运并转至全景，先预热约 1 秒，再自动旋转采样 8 秒，总计约 9 秒，报告平均 FPS、P95 帧间隔和样本数。不同设备与设置必须在固定窗口和场景条件下分别测量，本说明不填写未经本轮测量的运行数值。

按需重绘、共享实例合批、精确索引、状态缓存和局部矩阵更新减少重复工作。热图保留动画时仍需连续刷新；比较极致静止效果时应停止搬运、相机和热图粒子运动。功能测试及 GPU 替身测试验证程序合同，实际抗锯齿、帧率、阴影稳定性和设备兼容性仍由浏览器检查确认。

## 实物路线与证据边界

原 800 × 600 × 100 mm 底座、4 mm 面板、八个轻质模型的 XY 磁牵引原理样机继续作为独立验证对象。重量由面板承担，磁头升降用于吸合与释放，不能视为建筑房间的带载升降。V7 所沿用的紧凑框架在尺度、承重、驱动和接口上仍需要新的试验链。

| 阶段 | 需要形成的证据 |
| --- | --- |
| 平面原理复测 | 记录吸合、定位、连续搬运与失败原因，保留原始数据 |
| 单层承载与锁定 | 检查载荷交接、导向、落位锁定、附件净距与断电保持 |
| 两层升降 | 验证真实带载升降、制动、空载换层、收拢展开和故障状态 |
| 多层调度 | 验证占位约束、路径改道、接口互锁与恢复次序 |
| 标准接口与环境 | 分别验证气密、供电、数据、流体、热控、防尘、热真空与寿命 |
