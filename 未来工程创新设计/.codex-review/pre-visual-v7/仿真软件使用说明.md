# 月序 LUNARIS 6.0 · 紧凑模块聚落

双击 `月宫华容_三维仿真软件.html`，用支持 WebGL 的 Chrome 或 Edge 打开。成品内嵌场景、程序材质、规划器、交互和 Three.js，可离线运行，也可单独复制到其他电脑。观看成品无需安装 Node.js。

## 当前空间与尺度

第六版采用紧凑的积木式房间堆叠。24 个房间沿五层不规则轮廓组合，形成错层退台、局部悬挑和留空；精简框架藏在楼板与接缝中，A / B / C 三条内部通道承担升降。画面以房间组团为主体，落位后由框架支承并锁定。

| 项目 | V6 配置 |
| --- | --- |
| 空间层级 | L1 至 L5，共 5 层 |
| 有效节点 | 42 个，各层为 14 / 11 / 8 / 6 / 3 个 |
| 初始房间 | 24 个，各层为 9 / 6 / 5 / 3 / 1 个 |
| 初始空位 | 18 个，约占节点的 42.9%，包含内部升降节点和预留泊位 |
| 房间外包络 | X × Y × Z = 9.2 × 7.8 × 8.4 m |
| 相邻中心间距 | X / Y / Z = 10.2 / 9.2 / 9.6 m |
| 相邻外包络净距 | X / Y / Z = 1.0 / 1.4 / 1.2 m，概念几何尺寸 |
| 房间底面标高 | 3.4 / 12.6 / 21.8 / 31.0 / 40.2 m |
| 场景尺度 | 1 场景单位 = 0.1 m |
| 升降通道 | A、C 连通 L1—L5；B 连通 L1—L4 |

每层地图为 **5 列 × 3 行**，只显示有效节点；不规则轮廓外和中央留空不是可随意进入的搬运位置。空位比例是节点占用指标，不是建筑面积空置率。房间外包络不是可用室内尺寸，层距不是室内净高。

## 快速演示

1. 打开 HTML，等待月面聚落加载。初始为“科研协作”已就绪状态，点击底部“开始演示”。
2. 底部主栏直接选择 **1× / 2× / 4× / 8× / 16×**，默认 **4×**。倍速只改变观看速度，不改变目标布局或房间尺度。
3. 点击播放按钮暂停或继续；“重播”从当前计划开头播放。拖动时间轴会暂停并显示所选模拟时刻。观察载荷交接时可使用 1×。
4. 左侧切换预设任务会恢复统一初始布局、重新规划并自动播放。底部显示当前动作、完成搬运次数和计划搬运距离。
5. 右侧点击层号单独观察；再次点击同一层或“完整聚落”恢复全部楼层。点击已占用格位或三维房间可选中对象。

“场景与调度”中可启用循环演示和镜头跟随搬运。切换到后台标签页会暂停，返回后可手动继续。“模拟急停”冻结软件状态，点击底部“解除急停”继续；它没有模拟真实设备的断电制动或故障恢复控制。

## 三个预设任务

| 任务 | 搬运次数 | 可核对的终态 |
| --- | --- | --- |
| 科研协作 | 6 次 | R02、R03、R08 归集至 L2，二层协作房间由 0 增至 3，升降节点恢复空闲 |
| 维修隔离 | 6 次 | R24 从顶层移至首层东缘检修位，两处相邻普通位留空；R11 补入顶层 |
| 基地扩建 | 9 次 | 启用 L2 两处预留位，二层入驻由 6 增至 8；全站仍为 24 个房间 |

搬运包括必要的让位和中转，因此一次任务的搬运次数可能多于目标房间数。观察升降机构的收拢、空载换层、展开、房间解锁、水平平移、带载升降与落位锁定。程序按相邻节点、当前占位和扫掠包络检查路径；一次只有一个房间执行搬运。

“维修隔离”的缓冲表示空间留空，没有完成气密或污染隔离验证。“基地扩建”表示重组现有房间与启用预留位置，没有新增房间实体。

## 手动操作：先预览，再确认

推荐以初始布局中的 **R02：L1 · 后02 泊位 → L2 · 后04 泊位** 体验一次跨层搬运。

1. 打开“场景与调度”，取消“封闭 L2 · C 升降通道”，点击“恢复初始房间布局”。保持暂停，选择“完整聚落”。
2. 点击 L1 地图后排第二列的 R02，或直接点击三维 R02 房间，核对选中对象。
3. 点击“手动六向调度”。若已有房间正在搬运，程序会先完成该房间停靠，再进入手动模式并保留已完成布局。
4. 点击 L2 地图后排第四列的空闲位“后04 泊位”。左侧出现“搬运路线预览”，确认起终点与搬运距离；在“显示搬运轨迹”开启时查看三维路径。
5. 点击“确认搬运”开始执行，点击“取消”只撤销预览。示例路径经过 L1 · C 和 L2 · C，总搬运距离 **29.6 m**，其中 Y 向行程 **9.2 m**，底面由 3.4 m 升至 12.6 m。
6. 完成本次落位后，再选择下一房间或目标。

六向按钮与键盘选择相邻节点：A / D 对应 −X / +X，W / S 对应 −Z / +Z，Q / E 对应降层 / 升层。垂直按钮只在同一升降通道的相邻层之间生效。点击较远空位时，规划器尝试经过连通的空闲节点到达目标。

已占用、封闭或无连通路径的目标会被拒绝。程序不会为了执行单次手动指令自动搬走其他房间，需要先自行腾出通路。选择另一个房间会清除预览；切换预设任务会恢复该任务的统一初始布局。

## 观察与空间分析

| 控件 | 用途 |
| --- | --- |
| 全景 | 查看月面地形、紧凑堆叠轮廓和任务搬运路径 |
| 房间近景 | 暂停播放并显示所在单层，避免上层遮挡；观察外壳、窗体、设备与尺度参照 |
| 俯视 / 立面 | 比较不规则楼层轮廓、房间净距和升降高度 |
| 框架透视 | 观察楼板、内部支承、升降通道和房间之间的关系 |
| 自由漫游 | WASD 移动，Q / E 升降，Shift 加速，拖动改变朝向 |
| 人员通行 | 辅助讨论房间间的空间连接；按界面提示检查适用范围 |
| 舱内剖切 | 进入选中房间的单层近景，显示内部层板、设备与功能尺度，再次点击关闭 |

常规观察时左键拖动旋转，右键或 Shift + 拖动平移，滚轮缩放；触屏双指缩放与平移。空格播放 / 暂停，Esc 关闭面板或退出沉浸显示。自由漫游是观察镜头，没有模拟人员与墙体的碰撞限制。

第六版的房间运输图不等于独立、连续的气密人员通道。人员通行入口保留用于方案讨论，不能据此宣称载人通道已贯通或换算实际通行效率。任务效果以同层协作房间数、隔离缓冲位和入驻数量等布局指标核对，不沿用历史径向方案的人员距离数据。

## 检查封闭通道

勾选“封闭 L2 · C 升降通道”，重新选择“科研协作”。当前规划可通过 A / B 通道完成同一科研终态，应观察到路径改变，而不是穿过封闭节点。取消封闭后可重新生成原条件下的计划。

其他布局下，封闭或房间阻挡可能造成无可用路径，界面会说明原因。正在搬运时先完成落位，再修改影响当前路径的封闭条件。

## 画质与流畅度

默认“精细 · 光影与材质”保留 **4096 阴影贴图**、精细材质和画面后处理，像素比上限为 1.75。晨光适合观察体块与冷暖关系，白昼方便检查结构，夜景强调室内照明；可通过曝光调节明暗。

设备运行吃力时可主动切换“均衡 · 流畅优先”：像素比上限为 1，阴影贴图为 2048，使用较轻的渲染路径。拖动镜头时不会自动降低已选画质。

程序采用按需重绘，静止时减少持续绘制，相机操作复用相同模拟状态，活动对象和阴影按需要更新。这些优化减少重复工作，不承诺所有设备达到 60 FPS。面板中的 FPS、P95 帧耗时、绘制次数与三角形数是运行参考；静止时可能保留最近样本，不能代替目标设备的完整 GPU 测试。

## 导出记录与验证边界

点击“导出三维仿真记录”下载 `LUNARIS-XYZ-simulation.json`，内部版本为 **6.0**。记录包含配置、初始布局、42 个节点、A / B / C 升降通道、任务、路径、动作时序、操作事件、封闭节点和当前状态。

位置使用场景单位，换算米时乘以 `metresPerSceneUnit = 0.1`。当前状态中的升降机构高度与收拢程度用于还原机械搬运动画；搬运距离和模拟时长也属于当前参数下的结果。界面提供导出，没有记录导入按钮。

本版检查几何、连通、占位、扫掠包络及搬运动作时序。机械承载、升降驱动力、断电制动、锁定保持、气密接口、防尘热控与月面环境仍需独立计算和试验。原 800 × 600 mm 二维磁牵引样机只能支持对应的平面原理验证，不能证明建筑尺度的载人多层搬运已经可行。

## 源文件、构建与检查

| 文件 | 用途 |
| --- | --- |
| `月宫华容_三维仿真软件.html` | 可独立离线运行的最终成品 |
| `simulation-core.js` | V6 节点、占位、路线、任务与升降时序 |
| `lunar-scene.js` | 月面、紧凑模块聚落、材质与渲染 |
| `lunar-app.js` | 播放、预览确认、观察、分析入口和记录导出 |
| `lunar-ui.html` | 界面文案、五列三行楼层图和响应式样式 |
| `build-simulation.cjs` | 检查脚本语法并打包离线 HTML |
| `框架方案设计说明.md` | 第六版空间、机构与验证路线 |

修改源码后，需要重新构建 HTML 才能在成品中看到改动。旧 V4、V5 方案文档保留作历史对照；其中尺度、形态与运动架构不代表当前第六版。`simulation-app.js` 与 `simulation-ui.html` 不属于当前构建入口。

在项目目录使用 Node.js 执行：

```powershell
node build-simulation.cjs
node simulation-test.cjs
node lunar-validation.cjs
node .codex-review/v6-performance-test.cjs
```

核心检查覆盖 V6 规划、占位、扫掠、时序及终态；集成检查覆盖打包成品与界面联动；性能脚本检查按需重绘、相机输入、局部更新和倍速推进。集成与性能检查使用 GPU 替身，不证明真实设备的画质或帧率。

构建后在浏览器逐项查看三个任务终态、R02 手动预览确认、单层地图、内部升降、舱内剖切、通道封闭改道，以及精细画质下的拖动和缩放。人员通行入口按其概念边界说明使用。

近景观察时点击“全景”恢复全部楼层。点击播放也会恢复全景继续转运；剖切按钮保持独立开关。
