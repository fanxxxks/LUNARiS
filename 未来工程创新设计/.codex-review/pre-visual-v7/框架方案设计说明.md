# 可重构月球科研站 · 紧凑模块聚落方案 V6

第六版回到精简框架和内部机械搬运。房间如积木般紧密堆叠，以错层、退台、局部悬挑和中央留空形成不规则聚落；框架收进楼板与接缝，房间的体块、尺度和生活科研细节成为画面主体。月面背景继续保留。

col 为 −2 至 2，row 为 −1 至 1；X = col × 10.2 m，Z = row × 9.6 m。每层只保留实际有效节点，并不铺满五列三行。紧凑感由小净距和连续组团形成，初始空闲节点则服务于搬运与调度，两者使用不同统计口径。

尺寸是本轮可修改的几何假设。房间外包络不是室内净尺寸，楼层间距不是净高，留缝不代表已满足检修、消防、隔热或人员通行要求。机构、连接器和展开附件也须纳入后续完整运动包络。

## 总体形态与结构表达

底部房间组团较完整，上部逐层收退，避免规则塔楼式重复。框架以少量关键立柱、楼板边梁、舱底支承和接缝连接件表达承重关系；近景保留必要的导向、锁扣、服务接口和维护细节，远景以紧密体块读取整体。

局部悬挑需要明确回传至主结构的载荷路径。楼板和边梁应避开正在使用的搬运包络，不能仅通过隐藏构件掩盖结构冲突。房间落位时由固定支承承担载荷，搬运机构只在规定阶段接管。

可见的双层室内布置用于说明生活、科研与设备空间的尺度。人员参照、窗洞、设备柜和门高应彼此一致；外部散热板、通信与电力接口需要注明功能，具体面积与容量随热负荷和任务深化确定。

## 内部搬运逻辑

房间沿连通节点在 X、Z 方向平移，跨层必须经 A / B / C 内部升降通道。规划检查当前占位、相邻连接与连续扫掠包络，不允许穿越中央留空或跳过阻挡房间。较远目标通过多个相邻节点到达。

当前动画明确区分房间移动与空载机构调整：机构收拢 → 空载换层 → 展开接管 → 房间解锁 → 平移或带载升降 → 落位锁定。是否需要空载调整取决于机构的当前高度。一次只搬运一个房间，三套机构的状态独立记录。

实际工程顺序还需包括载荷接管确认、接口隔离、位置与锁定反馈、制动冗余及断电保持。收拢与展开的概念动画不等于真实机构的强度和稳定性验证。紧凑布置尤其需要检查机构突出部、局部悬挑、附件和检修空间。

三条通道提供替代路线，但能否改道同时取决于占位与连通。当前科研初态下，封闭 L2 · C 可以通过 A / B 完成同一终态；这不意味着任意故障和任意布局都能自动恢复。

## 三类任务与可核对结果

| 任务 | 当前搬运次数 | 目标与价值 |
| --- | --- | --- |
| 科研协作 | 6 次 | 将 R02、R03、R08 归集 L2，同层协作房间 0 → 3，减少空间上的跨层分散 |
| 维修隔离 | 6 次 | R24 从顶层迁至首层东缘，附近两个普通位留空；R11 补入顶层，表达检修与替位次序 |
| 基地扩建 | 9 次 | 启用 L2 两处预留位，入驻 6 → 8；全站 24 个房间守恒，表达既有空间的重组 |

让位与中转也是任务的一部分，搬运次数应统计完整计划。展示指标包括起终点、路径长度、升降段数、累计 Y 行程、机构状态、房间数量和终态。播放倍速、动画时长及布局变化不能直接当作真实效率、能耗或成本收益。

维修缓冲只表示空间留空。若目标是气密、污染、火灾或设备故障隔离，还需要对应接口、舱门、环境和运维设计。

## 人员通行与标准接口

保留“人员通行”入口是为了在空间讨论中检查连接需求。房间运输图不等于独立的气密走廊图，不能直接把运输节点连线定义为已贯通的载人道路。

后续人员图应分别建模房间入口、固定走廊、竖向交通、气闸和检修通道；每条边带有可通行状态、距离、连接类型与封闭条件。移动中的房间不得继续被当作稳定人员通道。确定完整图和真实门位之后，才能比较通行距离、绕行和疏散；本轮以布局指标评价三类任务。

固定接口至少分为机械、供电、数据、流体、热控及人员连接。建议的工程流程是关闭并确认舱门 → 隔离服务 → 接管载荷 → 解锁搬运 → 落位承重与机械锁定 → 连接区检漏 → 均压 → 恢复服务 → 满足条件后开门。当前软件并未逐项模拟这套气密规程，不应把动画阶段当作接口认证证据。

## 画面、交互与性能

- 形态以紧凑体块、退台阴影、板缝与局部设备建立真实尺度；框架细节服务于结构理解，避免淹没房间组团。
- 外壳采用微粗糙材质，边缘与接缝变化克制；窗体保留反射和室内层次，金属高光不过曝。
- 月面主光和接触阴影交代落地关系，暖色室内照明与冷色状态灯只在需要处强调。散热器、接口、舱门和设备应有功能依据。
- 全景、单层、近景、框架透视、舱内剖切和自由漫游各自承担清楚的观察目的；避免标签遮挡搬运动作。
- 手动操作先选房间与可达空位，预览路线后确认；保留取消、急停、倍速与记录导出。主栏提供 1 / 2 / 4 / 8 / 16 倍，默认 4 倍。
- 精细画质默认保留 4096 阴影贴图；按需重绘、状态缓存与局部更新减少重复工作，均衡画质由用户主动选择。性能需在目标设备测量，不承诺统一帧率。

## 实物路线与证据边界

原 800 × 600 × 100 mm 底座、4 mm 面板、八个轻质模型的 XY 磁牵引原理样机继续作为独立验证对象。重量由面板承担，磁头升降用于吸合与释放，不能视为建筑房间的带载升降。第六版紧凑框架在尺度、承重、驱动和接口上仍需要新的试验链。

| 阶段 | 需要形成的证据 |
| --- | --- |
| 平面原理复测 | 记录吸合、定位、连续搬运与失败原因，保留原始数据 |
| 单层承载与锁定 | 检查载荷交接、导向、落位锁定、附件净距与断电保持 |
| 两层升降 | 验证真实带载升降、制动、空载换层、收拢展开和故障状态 |
| 多层调度 | 验证占位约束、路径改道、接口互锁与恢复次序 |
| 标准接口与环境 | 分别验证气密、供电、数据、流体、热控、防尘、热真空与寿命 |

原方案提出的连续 20 次、19/20 成功和定位误差不大于 5 mm 等数值应保留为待测目标，实际结果由记录填写。当前仿真提供几何、占位、扫掠与时序证据，不替代机械强度、挠度、驱动、制动、密封和载人条件验证。

## 相对前期方案的调整

保留共享搬运、模块复用、周转空位、三类任务和分阶段实物验证。空间重新收紧为积木式不规则堆叠，外露框架退到楼板与接缝；尺度统一到可读的房间级，运动恢复为内部 XYZ 机械搬运。画质、预览确认、剖切、性能优化和操作记录继续保留。
