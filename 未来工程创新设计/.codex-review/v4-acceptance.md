# LUNARIS V4 验收记录

验收日期：2026-09-07。交付入口为项目根目录 `月宫华容_三维仿真软件.html`，源码由 `build-simulation.cjs` 打包，单文件离线运行。

## 空间与渲染

- 24 个房间，42 个不规则框架节点，五层，A / B / C 三条内部升降通道。
- 实体双层舱内物体、圆角承压外壳、透明玻璃、金属及月壤程序材质。
- 离线环境反射、高精度阴影、深度接触遮蔽、HDR 泛光、抗锯齿与三种光照。
- 实际几何统计：212 个 mesh，实例展开后约 603,300 个三角形。统计不等同于每帧实际绘制调用数。

## 自动验证

全部通过：

1. `node simulation-test.cjs`：三项任务 21 次搬运、25 段跨层；1,000 次合法随机移动（其中 205 次跨层），房间守恒、任务终态、封闭改路、机构独立状态、连续时序及确定性拖动。
2. `node lunar-validation.cjs`：成品 HTML 初始化、实际房间包络、三任务、播放与暂停、拖动、急停恢复、手动 X/Y、分层、沉浸、光照、画质、漫游、封闭改路及 JSON 导出。此项使用真实 Three 几何，GPU/DOM 替身。
3. `node .codex-review/v4-scene-clearance.cjs`：57 条合法图边对 468 个结构障碍盒与 52,576 个实际固定三角面的保守连续扫掠，及 20 组托架收拢/展开/空载及载荷升降扫描，零交集。

已修正收拢托架与侧轨干涉、托架装饰条穿入舱底、停靠支承叉与展开托架重叠，以及近景切换时的遗留指针状态。
