# V6 紧凑积木式聚落验收

本版按用户最新纠正，撤销径向风扇母港与推进器搬运，恢复精简框架内的 X / Y / Z 调度。

## 成品与形态

- 成品：`月宫华容_三维仿真软件.html`，离线自包含，约 784 KB。
- 24 个房间、42 个不规则节点、五层退台、A / B / C 三个内部升降通道。
- 房间包络 9.2 × 7.8 × 8.4 m；中心距 X / Y / Z 为 10.2 / 9.2 / 9.6 m，水平净间隔 1.0 / 1.2 m。
- 薄楼板梁与接缝细柱，去掉径向支臂、圆形母港、外露大斜撑和高出房间的顶部框架。
- 近景自动暂停并显示所在单层，避免密堆房间的前排及上层遮挡；全景和播放恢复全部楼层。

## 功能与性能验证

- `node simulation-test.cjs`：1,000 次随机转运、205 次垂直转运；21 个任务搬运、25 段升降；1,540 次紧凑托架折叠/展开包络检查；缓存与序列化 seek；0.5–16 倍速终态一致。
- `node lunar-validation.cjs`：最终打包 HTML 14/14 通过，覆盖手动预览确认、预览失效、XYZ 转运、急停、时间轴、单层和剖切、人员通行示意、封闭改路、记录导出、按需渲染停止前的最终状态更新。
- `node .codex-review/v6-performance-test.cjs`：11/11 通过。静止 180 帧无重复状态计算、绘制或实例上传；未按下鼠标的移动不重绘；拖动/平移/缩放下一帧达到输入位置；只有移动房间上传实例；单 RAF 链；主栏 1 / 2 / 4 / 8 / 16 倍速，默认 4。
- 保留精细默认、4096 阴影、PBR 材质、室内细节与完整后处理；公共部件合批、精确顶点索引和局部实例更新继续生效。
- 上述性能检查使用 GPU 替身，仅证明计算与提交行为，不代表真实设备帧率。

## 实际场景几何

独立 `v6-clearance.cjs` / `v6-clearance-report.json`：

- 28,146 个相关固定三角面。
- 57 条房间运动边和 20 种托架动作连续扫掠，零冲突。
- 4,592 个停车支承交接姿态，零同时可见穿插。
- 审计发现并修复了薄梁边界导条与收拢托架的冲突，以及停车支承在主托架接管时的显示重叠。
- 范围是几何净空与动作时序，不是承重、容差、人员净宽或气密认证。

## 浏览器核对

- 在默认 1081 × 898、1280 × 720、375 × 812 下检查全景与控制布局，无页面横向溢出。
- 查看实际精细全景、剖切室内、夜景、五层地图与主栏倍速；真实运行 16 倍科研任务至结束。
- 实际浏览器采样中帧率会随窗口、阴影更新及阶段变化；一次高画质播放读到约 21 FPS / P95 66.9 ms，不能据此声称稳定 60 FPS。本版通过消除输入缓动迟滞与重复工作改善响应，未默认降低画质。
- 浏览器控制台未观察到运行错误。
