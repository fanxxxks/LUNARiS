# 健身房

R23 的重复工程工坊改为 GYM 健身房，基地保持 24 个房间、五层布局和原有六向舱口。沿用已有双层舱体、墙板、地板、钢材、橡胶和织物纹理，桌面使用同一贴图库的哑光涂层。

- 下层：乒乓球桌、网格球网、两支球拍及球，双跑步机，拉伸垫、毛巾柜和水瓶。
- 上层：力量训练架、杠铃及配重、卧推凳，双动感单车、哑铃架及收纳。
- 器材放在原有三个设备区，中央十字通道和右后方梯道保留。

在「房间图鉴 → 健身房」中切换完整外观、下层内饰和上层内饰。可向自然语言调度输入「冯院长去健身房停留 5 秒」。健身需求已加入自主活动池，总计九类房间、51 项需求；运动器材为静态模型，尚无实际击球或器械训练角色动画。

验证：`npm run test:character` 10 项通过；`node scripts/check-gym-browser.cjs` 验证图鉴、双层剖面、完整外观、健身房名称解析及实际规划、390 像素宽度布局，无页面脚本错误。截图及规划结果位于 `docs/gym-validation/`。
