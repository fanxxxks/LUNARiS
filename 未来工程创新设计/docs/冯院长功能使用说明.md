# 冯院长人物与行程

当前实施分支：`codex/feng-peng-character-runtime`（原规划分支为 `codex/feng-peng-character-routing`）。

打开高性能仿真启动器，点击右上角冯鹏头像展开深色半透明卡片，再点头像、卡片关闭按钮或 Escape 收起。卡片显示当前位置、想法、当前阶段与行程，只占局部区域；头像已嵌入离线 HTML。

面板右上人物展示区默认显示 朝左略微低头的冯鹏侧脸立绘，点击或按 Enter/空格切换为行走模型，再点返回立绘。行走模型是独立预览，不改变场景中冯院长的当前位置、任务或暂停状态。收起面板或切回立绘时停止预览绘制；预览复用模型与行走动画，使用单独骨架及 1K 预览纹理，沿用应用主循环。

“人物高亮”是独立开关，默认开启，控制荧光黄人物轮廓、脚下定位环及头顶标记；关闭后仍保留正常人物。隐藏人物会同时隐藏这些高亮，但保留开关偏好。场景中的想法气泡已移除，想法只显示在侧栏。

点击“跟随观察”会剖开人物所在房间并显示当前内部楼层；点击“退出跟随”返回原视图和楼层范围。主动选择全景、其他视图或楼层也会退出跟随，避免下一帧重新隐藏其他楼层。人物沿用原有渲染循环，不另建渲染线程。

## 操作

- **自主活动**：默认在待机 30 秒后按需求选择目的地，可以调整待机时间或关闭自主活动。
- **自然语言**：点击“用自然语言安排行程”，输入“冯院长先去 R14 停留 5 秒，再去 R20 停留 8 秒并挥手”。冯鹏、冯院长、冯老师均指同一人。
- **舱内跨层**：“冯老师去 R20 上层停留 5 秒”，从下层通过梯道到上层；“去 R20 下层”返回。
- **暂停/继续**：冻结当前人物或人物调度产生的房间搬运；不会累计自主待机时间。
- **停止**：取消后续任务并关闭自主活动。搬运或通行途中先到安全停靠/前室节点，再停止；新人物指令使用同样的安全接管机制。
- **显示人物**：仅控制可见性，自主开关和任务状态另行控制。
- **导出**：原有仿真导出同时包含人物位置、行程、需求完成记录和事件。

明确编号的基础人物指令在离线 HTML 内可解析；复杂自然语言需要本机服务。功能名对应多个房间时会提示准确编号，不会静默选错舱室。

## 活动范围

目前配置 45 项活动，覆盖居住、生命支持、能源、生物培养、医疗、工程工坊、数据核心、指挥共 8 类舱室。包含不同理由、活动点、停留、完成反馈和冷却，并支持“登记样本 → 分析数据 → 汇报研究进展”等短活动链。

每项自主活动有独立的第一人称动机，描述想做的事及兴趣、休息或生活需求，例如“我一直惦记着那几盘幼苗，想凑近看看新叶子有没有变化”。搬运与行走时保留动机，不再用路程或下一站信息覆盖想法；路线信息在状态、进度及行程中单独显示。

首版活动主要表现为到指定设备附近观察、待机及明确指定的挥手/推行动作；吃饭、坐卧、精细工具操作的专用动作尚未制作，不能将当前表现视为这些动作已经完成。

自主展示保证每连续两次完成的自主行程中至少一次包含实际房间搬运。上次仅步行时，下次优先生成未连通房间对应的需求，并约束规划必须搬运当前房间或目的房间；无关房间移动不计数，搬运完成并到达后才更新计数。全部房间类型仍参与需求生成。自然语言指定行程保留原有顺序和效率规则，不强制这个展示节奏。若通道限制导致无法规划，会保留角色并提示，不能用纯步行冒充必需的搬运。

## 调度规则及边界

搜索在 Worker 中运行，比较纯步行、移动载人房间、移动目标房间和其他房间让位方案。搬运时间采用现有机械仿真时间轴，人物停靠后再行走，移动中的舱室不作为通行连接。

允许经过中转房间，但正式到访顺序保持不变。优先预计总到达时间，耗时差在最快候选的 5% 且不超过 2 秒以内时优先减少步行。多站指令对下一站做有限候选前瞻，到站后按最新布局重新规划。

这是限时搜索中的候选比较，不保证全局最优。想法和日志不把未模拟的故障、健康或库存数据当成真实事件。当前导航依赖房间中的固定公共通道和活动点，新增内饰障碍需要同步更新导航。

## 验证

`npm run test:character` 验证姓名、顺序、重复访问、停留、全部类型需求、冷却、跨层轨迹、不可达、搬运合法性及锁定。

`scripts/check-character-browser.cjs` 用 Playwright 检查实际页面的加载、两站行程、暂停、挥手和上梯，并输出 `docs/character-validation/`。可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 包，`LUNARIS_TEST_URL` 指定测试服务地址。该无头浏览器验证不代表 240 Hz 显示器上的实际帧率。

2026-09-08 验证结果：7 项核心/服务测试通过；实际页面按顺序到访 R14、R20，完成停留、挥手、上下梯及自主目的地生成，未出现页面脚本错误。详细事件见 `docs/character-validation/browser-report.json`。

本次人物高亮与侧栏修改后的检测：同一 1600×1000 视口、精细画质、高性能 GPU 启动参数下，无头 Edge 镜头旋转时隐藏人物 102 FPS，显示人物及高亮 92 FPS，两组 P95 均为 16.9 ms；使用 RTX 5060 Laptop GPU。记录见 `performance-report.json`。数值受当时浏览器调度及整机并发任务影响，不与其他时间的检测直接比较。

当前会话新版本机服务另开在 `http://127.0.0.1:8791`，避免中断既有 8787 服务。以高性能启动器打开该端口，可在 PowerShell 运行 `$env:LUNARIS_PORT='8791'; & '.\启动高性能仿真.cmd'`。原启动器默认端口保持 8787。

2026-09-09：9 项核心/服务测试通过。浮层与高亮验证见 `panel-report.json`：头像展开、独立高亮开关、无场景气泡、动机保留、退出跟随恢复 24 个房间、Escape 收起和 390 像素窄屏布局均通过。`scripts/check-character-cadence.cjs` 仅在测试响应中加速人物时间，实际完成 4 次自主行程，搬运次数依次为 0、2、1、2，验证每相邻两次行程至少一次搬运，并验证全景与手动楼层选择不再被跟随覆盖；没有页面脚本错误。记录见 `cadence-report.json`。

立绘及行走预览验证：`scripts/check-character-portrait.cjs` 检查默认立绘、实际画面中的步态变化、鼠标/键盘切换、任务暂停时独立预览、收起停止绘制、重新展开恢复、窄屏图文不重叠。结果见 `docs/character-validation/portrait-report.json`。

侧脸立绘使用独立轮廓遮罩去除外部背景，人像不透明度为 94%，不使用提亮混合来隐藏背景，因此黑色衣服保持正常细节。
