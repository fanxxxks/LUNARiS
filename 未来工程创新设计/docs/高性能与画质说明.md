# 高性能与最高画质

2026-09-09。默认采用高性能模式；在“基本设置”的画质选择中可切换“电影级 · 最高画质”。冯院长面板内也有高性能开关，关闭后进入精细画质。

## 跟随显示修复

此前人物跟随每帧强制设置人物所在楼层，其他楼层被主动过滤，这不是显卡未加载成功。现在跟随保留全部 24 个房间；跟随剖切只影响当前房间，搬运中不剖切。镜头沿当前观察方向退出建筑及移动模块的包围区域，避免近距离镜头进入其他房间或楼板。真实遮挡仍然存在，可用人物高亮辅助定位。

发生 WebGL 上下文丢失时冻结人物与搬运进度，恢复时重新上传全部房间实例、重建渲染设置。此机制可处理浏览器允许恢复的上下文丢失，不能保证显卡驱动崩溃等外部故障一定恢复。

## 渲染档位

| 项目 | 高性能 | 精细 | 电影级最高画质 |
| --- | --- | --- | --- |
| 房间、内饰和材质 | 完整 | 完整 | 完整 |
| 常规主画面渲染通道 | 2 | 5 | 5 |
| 多重采样 | 关闭，使用 FXAA | 最高 4× | 最高 8× |
| 阴影贴图 | 2048 | 4096 | 6144 |
| 环境遮蔽 | 关闭 | 半分辨率 8 采样 | 全分辨率 32 采样 |
| 静止画面积累 | 无 | 无 | 16 个抖动采样帧 |
| 主画面像素预算 | 约 369 万上限 | DPR 上限 1.75 | DPR 上限 2 |

多重采样和阴影尺寸以设备实际支持为准；手动抗锯齿设置可覆盖自动采样。高性能档将变化中的阴影刷新限制在 30 Hz，最后一次更新也会刷新；主画面、人物和镜头不受这个阴影频率限制。关闭的后处理目标释放为最小尺寸，减少显存占用。

最高画质增加轻微冷暖光影分离及渐变抖动。运动时不做静态积累，避免人物及搬运拖影。它是目前项目的最高渲染档位，尚不等同于完整 3A 游戏画质：高质量环境反射、间接照明、精细人物皮肤与衣料、近景材质和动画仍需要后续资产及渲染工作。不能把提高采样数视为这些能力已经实现。

## 验证

`scripts/check-follow-rendering.cjs` 在实际页面中执行 R23 → R20 上层 → R02 的跨层路线，连续检查全部房间实例、非有限矩阵、批次包围球、镜头防穿入及搬运时外壳；覆盖暂停、切换画质和模拟 WebGL 丢失恢复。测试只在浏览器响应里加速人物时间，不改变生产时间轴。

`scripts/check-render-quality.cjs` 检查三档画质、最高档 16 帧静态积累、4K 视口下高性能像素预算。记录在 `follow-validation/`。本机无头 Edge / RTX 5060 Laptop、1600×1000 视口旋转检测分别达到 239、240、240 FPS，P95 为 4.3 ms；这是该次自动化环境的数据，不代表用户桌面窗口、所有场景或最高分辨率下的帧率保证。
